## GitHub activity

Stats cards were rendered from public data on October 3, 2026, using the maintained GitHub Stats Extended service. They do not represent private employer activity. Language percentages measure repository bytes, not proficiency.

- [Renderer 2.2.1](https://github.com/stats-organization/github-stats-extended/tree/v2.2.1), MIT © 2020 Anurag Hazra, Abhijit Gupta, martin-mfg.
- [Bundled renderer MIT license](./stats-renderer-LICENSE.txt)
- [Pinned Stats Action](https://github.com/stats-organization/github-readme-stats-action/tree/2c498845f71017821efaad14293ebc736156ef21), MIT © 2025 stats-organization.
- Commit counts use the current UTC calendar year, not all-time totals or a rolling year.
- Original metrics are retained: stars, commits, pull requests, merged pull requests, merged percentage, reviews, issues, discussions started/answered, and contributed repositories.
- Language cards retain normal layout and the original five-language coverage.
- Stats cards are static. The setup diagram has one three-second signal; reduced-motion selects separate static assets.
- The existing 3D chart and generator remain unchanged. The local draft contains current chart copies solely for preview; they are excluded from the publication changes.
